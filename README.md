# janari
Render X3DJSAIL apps with ANARI

To build:

Install:
Install ANARI-SDK-0.16.0/ in this folder.
Install anari-java/ in this folder.

To run:

```bash
bash runnable.sh
bash run.sh net/coderextreme/data/ArchHalf
bash run.sh net/coderextreme/data/BoxEm
bash run.sh net/coderextreme/data/JinWink
````
